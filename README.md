# Журнал викладача

Облік проведених пар і розкладка паперового журналу для викладачів КФК СумДУ: https://dl-kfk.github.io/kfk_journal/

- Оберіть себе у списку викладачів коледжу: дисципліни, групи й пари створяться з розкладу.
- Завантажте силабус єдиної форми (.docx або .pdf): тематичний план береться з розділу «7.1 Види навчальних занять».
- Заміни зі сторінки розпоряджень і перелік пар від навчальної частини вставляються копіюванням таблиці.
- Розкладка журналу: 18 колонок на лівій сторінці, до 20 рядків на правій, колонки атестації, перездачі й підсумкових.

Записи зберігаються лише у вашому браузері. Регулярно завантажуйте резервну копію («Налаштування» → «Резервна копія»): нею ж переносять журнал на інший комп'ютер.

`kfk_rozklad.json` — знімок розкладу з https://kfk.sumdu.edu.ua/studentu/rozklad-dlia-vykladacha-koledzhu/. Його щопонеділка оновлює GitHub Actions (`.github/workflows/rozklad.yml`, скрипт `update_rozklad.py`), а вручну — вкладка Actions → «Оновити розклад викладачів» → Run workflow.

Сторінка збирається з `head.html`, `parsers.js` і `main.js` командою `python3 build.py` (робоча тека автора).
